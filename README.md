# Hifz Companion

Hifz Companion is a real-time Qur'an memorization companion that listens to a user's recitation and helps identify possible memorization mistakes while they recite.

## Project Goal

The goal is to build a system that can:

- Listen to Qur'an recitation in real time
- Recognize the Arabic words being recited
- Track the user's position in the expected Qur'an text
- Detect possible skipped, repeated, or unexpected words
- Provide immediate feedback during recitation

## Initial Proof of Concept

The first milestone focuses on:

- One Qur'an ayah
- Microphone input
- Arabic speech recognition
- Expected Qur'an word sequence
- Basic sequence alignment
- Detection of at least one possible mismatch
